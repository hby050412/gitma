# 编号标注插件 — 用户使用指南

> **版本**: v1.1 · 2026-08-08

---

## 一、插件简介

在 Figma 画布上添加**圆形编号点**，用于设计评审、走查、反馈标注。编号点自动编号（插入/删除自动重排），关联图层后随图层移动，备注集中管理并同步显示在画布浮窗中。

**适用环境**：Figma 桌面客户端 + 浏览器（网页版）

---

## 二、安装方法

**桌面客户端**（仅需操作一次）：

1. 打开 Figma 桌面客户端，进入任意设计文件
2. 左上角 **Figma 图标** → **Plugins** → **Development** → **Import plugin from manifest...**
3. 选择项目目录下的 `manifest.json`
4. 之后在 **Plugins → Development → 编号标注** 即可运行

**浏览器（网页版）**：使用桌面端导入一次后，网页端刷新页面即可在 Plugins 菜单中找到并运行。

---

## 三、快速上手（30 秒）

```
1. 在画布上选中要标注的图层（如一个按钮、一张图片）
2. 打开插件，点击「＋ 添加」
3. 编号点出现在图层左上角，自动关联该图层
4. 在面板的备注卡片中输入说明文字
5. 完成！图层右侧自动出现备注浮窗
```

### 小浮标（收起态）

- 插件启动后显示为 📌 小浮标，点击展开为完整面板
- 面板右上角「━」收回到浮标
- 浮标始终悬浮，方便随时调出

## 五、功能详解

### 5.1 添加编号点

| 操作 | 结果 |
|------|------|
| 选中图层 → 点「＋ 添加」 | 编号点出现在**图层左上角**，自动关联该图层 |
| 没选中图层 → 点「＋ 添加」 | 提示"请先选中要标注的图层" |
| 快捷键 `Ctrl/Cmd + Shift + A` | 同上 |

编号自动分配（当前最大序号 + 1）。删除中间编号点后，后面的编号**自动顺延**，浮窗序号同步更新。

### 5.2 拖拽编号点（自动关联）

- 直接拖拽编号点可改变位置
- **自动关联**：编号点拖到哪个图层内，就自动跟随哪个图层移动；拖到空白处自动解除关联（变为独立编号点）
- 关联的图层移动时，编号点自动跟随（拖动容器时，容器内子组件绑定的编号点同样跟随）

### 5.3 锁定 / 解锁

- 选中编号点 → 点「🔓 锁定」（或快捷键 `Ctrl/Cmd + L`）
- 锁定的编号点**不可修改**：拖不动、缩不了、翻不了、改不了颜色——任何操作都会被自动复位并提示
- 锁定时圆形变为灰色
- 卡片上的状态标签会显示「🔒 已锁定」
- 未选中编号点就点锁定，会提示"请先在画布上选中要锁定的编号点"

### 5.4 备注编辑

- 在面板备注卡片的**文本输入框**中输入，输入即保存（防抖 300ms，失焦立即保存）
- 支持中文输入法流畅输入
- 输入内容实时同步到画布浮窗
- **浮窗为只读展示**，编辑统一在面板完成

### 5.5 备注浮窗（画布）

| 操作 | 行为 |
|------|------|
| 添加编号点后 | 浮窗自动出现在**关联图层的右侧**，顶部对齐；同图层多个编号点从上到下排列（间隔 8px） |
| 点击编号点 | 浮窗临时跳到编号点旁（查看用） |
| 点击画布空白处 | 浮窗回到图层右侧 |
| 点击浮窗 | 浮窗关闭 |
| 新建编号点 | 其浮窗自动**置顶**（不被其他浮窗遮挡，利于编辑） |

### 5.6 删除编号点

> ⚠️ **编号点只能通过插件删除**

- 画布上按 Delete 键删除编号点会被**自动恢复**（防误删），并提示"请通过插件面板删除"
- 正确删除方式：面板卡片上的「🗑 删除」按钮
- 删除后自动重编号 + 浮窗同步删除 + 剩余浮窗自动补位

### 5.7 搜索编号

- 搜索栏输入编号数字（如 `3`），列表**实时过滤**，只显示编号 3 的卡片
- **精确匹配**：输入 3 不会匹配 13/23/30
- 状态栏显示"匹配数/总数"；未找到时显示提示
- 点击「✕」清除搜索

### 5.8 全局设置（⚙ 设置面板）

点击「⚙ 设置」弹出设置面板，所有设置**作用于全部编号点**（锁定的编号点跳过）：

| 设置 | 说明 | 范围 |
|------|------|------|
| 🎨 颜色 | 12 色预设色板，点击即换色 | 编号点 + 浮窗序号圆同步变色 |
| ⭕ 大小 | 编号点尺寸（±2 步进或直接输入） | 12-60px，数字字号自动跟随 |
| 📏 浮窗长度 | 备注浮窗宽度（每行字符数） | 8-60 字/行，按标准字号换算 |
| 🔤 字号 | 备注文字大小 | 10-16 |

设置**自动保存**，下次打开插件仍然生效。

### 5.9 定位

- 面板卡片「📍 定位」：画布滚动到该编号点并选中

## 六、快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + Shift + A` | 添加编号点 |
| `Ctrl/Cmd + L` | 锁定/解锁选中的编号点 |
| `Delete / Backspace` | 面板中选中卡片时删除（画布上 Delete 无效，会被恢复） |
| `Esc` | 关闭设置面板 / 收起面板 |

## 七、常见问题

**Q1: 编号点被我不小心删了（画布 Delete）？**
A: 不用担心，插件会自动恢复它。要真正删除请用面板的「🗑 删除」按钮。

**Q2: 为什么编号点不跟图层移动？**
A: 检查编号点是否关联了图层——拖到空白处会自动解除关联。把它重新拖到目标图层内即可恢复关联。

**Q3: 锁定的编号点变灰色了？**
A: 灰色表示锁定状态。点卡片上的「🔒 解锁」或选中后按 `Ctrl+L` 解锁，恢复为当前配置的颜色。

**Q4: 中文输入备注总是断字？**
A: 已修复。现在输入时不会重渲染列表，中文可流畅组词。

**Q5: 插件关闭后编号点还在吗？**
A: 在。所有数据随 Figma 文件保存（PluginData），下次打开插件完整恢复。

**Q6: 其他协作者能看到编号点吗？**
A: 画布上的编号点图形和浮窗可见；但备注面板、编辑、搜索等交互需要安装本插件。

**Q7: 为什么画布上按 Delete 删不掉编号点？**
A: 这是删除保护设计——编号点只能通过插件面板删除，防止误删。

---

## 八、已知限制

- 插件**未运行时**，画布上删除编号点无法拦截恢复
- 跨页面的编号点恢复暂不支持（插件只管理当前页）
- 浮窗内容超过 120 字符时截断显示（完整内容在面板中）
