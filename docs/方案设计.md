# Figma 编号标注插件 — 方案设计

> **版本**: v1.1  
> **日期**: 2026-08-08  
> **状态**: 已实现 — 迭代中（实际实现与原始方案的差异见「十一、实际实现变更记录」）

---

## 一、概述

一款 Figma 插件，允许设计师在画布上添加可拖拽的圆形编号标注点，所有标注点的备注说明集中管理在一个可拖拽浮动面板中。支持自动编号管理（插入/删除时自动重排），编号点跟随目标图层移动。

**运行环境**: 浏览器（Figma Web） + 桌面客户端（Figma Desktop）

## 三、数据模型

### 3.1 编号点数据结构

每个编号点是一个 Figma Group 节点（圆形 + 文字），通过 `node.setPluginData()` 存储以下元数据：

| 字段 | Key | 类型 | 说明 |
|------|-----|------|------|
| 标注ID | `annotationId` | string (UUID) | 全局唯一标识 |
| 排序序号 | `order` | number | 1-based，决定显示的数字 |
| 目标图层ID | `targetNodeId` | string | 被标注的 Figma 节点 ID |
| X偏移 | `offsetX` | number | 相对目标图层左上角的 X 偏移 |
| Y偏移 | `offsetY` | number | 相对目标图层左上角的 Y 偏移 |
| 备注内容 | `note` | string | 用户输入的备注说明文字 |
| 是否锁定 | `isLocked` | string ("true"/"false") | 锁定后禁止拖拽移动 |
| 创建时间 | `createdAt` | string (ISO) | 用于辅助排序 |

### 3.2 编号点节点结构（Figma 画布）

```
Group (annotation-marker)
├── Ellipse (圆形背景)
│    - size: 24×24px
│    - fill: 主题色（如 #4A90D9）
│    - stroke: 2px 白色描边
└── Text (编号数字)
     - characters: "1"
     - fontSize: 12px
     - fill: #FFFFFF
     - textAlign: CENTER
```

所有编号点 Group 节点统一命名规则：`[Annotation] #1`、`[Annotation] #2` 等，便于识别和查找。

### 3.3 目标图层关联数据

在被标注的目标图层上存储指向编号点的反向引用：

| 字段 | Key | 说明 |
|------|-----|------|
| 关联编号点ID列表 | `annotationRefs` | JSON 数组，如 `["id1","id2"]` |

用于双向查询：知道目标图层 → 找到它所有的编号点。

**极简单色** — 白色为主，单一蓝色作为强调色，灰阶辅助。干净、克制、不抢设计内容的注意力。

## 五、核心功能设计

### 5.0 插件 UI 双态模式

插件 UI 有两种形态，通过点击切换：

```
┌─────────────────────────────────────────────┐
│  收起态（小浮标）                             │
│                                              │
│    ┌────┐                                    │
│    │ 📌 │   ← 始终悬浮在界面上，不遮挡画布     │
│    └────┘                                    │
│      │ 点击                                   │
│      ▼                                        │
│  展开态（完整面板）                            │
│  ┌──────────────────────────────────┐        │
│  │  🔧 工具栏                        │        │
│  │  [+ 添加] [🔒锁定] [━ 收起]       │        │
│  ├──────────────────────────────────┤        │
│  │  备注列表                         │        │
│  │  ① ...                           │        │
│  │  ② ...                           │        │
│  │  ③ ...                           │        │
│  └──────────────────────────────────┘        │
│      │ 点击「收起」按钮                        │
│      ▼                                        │
│    ┌────┐  收起到浮标                         │
│    │ 📌 │                                     │
│    └────┘                                     │
└─────────────────────────────────────────────┘
```

**技术实现**:
- 初始加载: `figma.showUI()` 以紧凑尺寸显示（~48×48px），仅展示图标浮标
- 点击浮标展开: `figma.ui.resize(320, 480)` 展开为完整面板
- 点击收起按钮: `figma.ui.resize(48, 48)` 收回到浮标
- 浮标默认位置: 由 Figma 控制（用户也可自行拖拽插件窗口）

**浮标样式**:
- 尺寸: 48×48px
- 图标: 📌 图钉图标
- 背景: 主题色圆角方块，带轻微阴影
- 始终置顶（插件 UI iframe 特性）

### 5.1 添加编号点

**触发方式**:
- 工具栏"+"按钮
- 快捷键（如 `Ctrl/Cmd + Shift + A`）

**流程**:

```
用户选中目标图层（可选，不选则以当前页面为参照）
     │
     ▼
用户点击"添加编号点"
     │
     ▼
插件在画布中心（或用户鼠标点击位置）创建编号点 Group
     │
     ├── 1. 获取当前视口中心坐标
     ├── 2. 创建 Ellipse(圆形) + Text(数字) → Group
     ├── 3. 分配下一个可用序号（当前最大 order + 1）
     ├── 4. 存储元数据到 PluginData
     ├── 5. 如果已选中目标图层，自动建立绑定
     └── 6. 备注面板新增一条空白备注条目，自动聚焦
```

**关于"鼠标指定位置"的限制说明**:

Figma 插件 API 无法直接监听画布上的鼠标点击事件（插件沙箱运行在独立上下文中）。采用 **方案 C**（智能预定位）：

```
用户点击"添加"按钮
    │
    ├── 已选中目标图层 → 编号点出现在图层右侧偏移 40px 处（贴近目标）
    └── 未选中图层     → 编号点出现在当前视口中心
    │
    ▼
用户拖拽编号点到最终位置（通常只需微调）
```

- 创建时自动将当前选中图层绑定为目标图层（有选中时）
- 未选中时，编号点以当前 Page 为参照，用户后续可手动绑定目标图层

### 5.2 拖拽编号点

- 用户在画布上选中编号点 Group，拖拽移动
- 插件监听 `documentchange` 事件，检测编号点位置变化
- 位置变化时自动更新 `offsetX` / `offsetY`（相对目标图层的偏移量）
- 如果 `isLocked = true`，插件检测到位置变化后立即将其复位（阻止拖拽）

**锁定状态下的拖拽处理**:
- 锁定编号点被拖拽时，插件在 `documentchange` 中检测位置变化
- 自动将编号点移回原位（基于存储的 offset 重新计算绝对坐标）
- 同时 UI 面板提示"该编号点已锁定"

### 5.3 锁定 / 解锁

**触发方式**:
- 工具栏"锁定"按钮（选中编号点后可用）
- 快捷键（如 `Ctrl/Cmd + L` 切换锁定状态）
- 备注面板中每条备注旁边的锁定图标

**锁定状态表现**:
- 画布上锁定编号点显示不同样式（如圆形加锁图标或颜色变灰）
- 备注面板中对应条目显示锁定图标

### 5.4 删除编号点

**重要限制**: Figma 插件 API 不提供画布节点的自定义右键菜单。为支持"右键删除"，采用以下方案：

**方案**: 选中编号点 → 按 `Delete` / `Backspace` 键删除。插件检测到编号点被选中后，在备注面板中显示删除按钮；也可通过快捷键删除。

**流程**:
```
用户选中编号点 Group
     │
     ▼
按 Delete 键 / 点击面板删除按钮
     │
     ▼
1. 检查是否有确认需求（可选）
2. 删除编号点 Group 节点
3. 清理 PluginData
4. 触发重编号：所有 order > 被删除order 的编号点，order - 1
5. 更新所有受影响编号点的显示数字
6. 备注面板对应条目移除，其余条目序号更新
```

### 5.5 自动重编号

**插入场景**（在序号 3 和 4 之间插入新编号点）:

```
插入前: [1] [2] [3] [4] [5]
                 ▲ 在此插入
插入后: [1] [2] [3] [4] [5] [6]
                 ▲ 新点=4，旧4→5，旧5→6
```

**删除场景**（删除序号 3）:

```
删除前: [1] [2] [3] [4] [5]
                 ▲ 删除
删除后: [1] [2] [3] [4]
              ▲ 旧4→3，旧5→4
```

**重编号执行逻辑**:
1. 获取所有编号点，按 `order` 升序排列
2. 确定操作类型（插入/删除）和影响范围（起始 order）
3. 从影响范围开始，依次更新 `order` 值
4. 更新每个编号点的 Text 子节点（数字字符）
5. 发送更新后的完整列表到 UI 面板
6. 备注面板同步更新条目序号和排列

### 5.6 位置跟随（目标图层移动时）

**原理**: 存储编号点相对目标图层的偏移量，当目标图层位置变化时，重新计算并更新编号点位置。

**实现**:
```
注册 documentchange 监听
     │
     ▼
每次文档变更时:
     │
     ├── 遍历所有编号点的目标图层
     ├── 检测目标图层是否发生位置变化（x, y）
     ├── 如果变化:
     │   ├── 新 X = targetNode.x + offsetX
     │   ├── 新 Y = targetNode.y + offsetY
     │   └── 更新编号点 Group 的 x, y
     └── 跳过锁定编号点的自动复位判断
         （需区分用户拖拽 vs 目标移动 → 通过标记位区分）
```

**偏移量计算**:
- 创建编号点时：`offsetX = 编号点.x - 目标图层.x`，`offsetY = 编号点.y - 目标图层.y`
- 用户拖拽编号点后：重新计算偏移量并更新 PluginData
- 目标图层移动时：`编号点新位置 = 目标图层新位置 + 偏移量`

**"区分用户拖拽 vs 插件移动"的机制**:
- 插件在程序化移动编号点时，设置全局标记 `isProgrammaticMove = true`
- `documentchange` 检测到编号点位置变化时：
  - 若标记为 true → 这是跟随目标图层的移动，清除标记，不更新偏移量
  - 若标记为 false → 这是用户手动拖拽，更新偏移量

```
│  ┌──────────────────────────┐    │
│  │ ③ ...                     │    │
│  └──────────────────────────┘    │
│                                   │
└──────────────────────────────────┘
```

**收起态布局**:
```
┌────┐
│ 📌 │   ← 48×48px 浮标，点击展开
└────┘
```

**面板拖拽**: 利用 Figma 原生插件窗口的可拖拽特性，用户可自由移动插件 UI 窗口位置。收起态和展开态均可拖拽。

**面板锁定**: 通过插件内部状态控制。锁定后在 UI 中显示锁定图标。收起态时浮标本身也可锁定，防止误触拖拽。注意 Figma 不提供 API 来固定 iframe 的屏幕位置，锁定为插件内部逻辑控制。

### 5.8 点击编号点 → 临时浮窗

**流程**:
```
用户点击/选中画布上的编号点 Group
     │
     ▼
selectionchange 事件触发
     │
     ▼
检测选中节点是否为编号点（通过 PluginData 判断）
     │
     ▼
是 → 获取该编号点的备注内容
     │
     ├── 方案 A（推荐）: 在画布上创建一个临时 Frame，显示备注文字
     │   - 位置: 编号点右下方偏移(30, 10)
     │   - 样式: 白色背景，圆角，带阴影
     │   - 内容: 备注文本（只读展示）
     │   - 关闭: 手动点击浮窗上的关闭按钮才关闭（不会因切换选中而自动消失，方便用户边看浮窗边操作其他图层）
     │
     └── 方案 B: 通过 postMessage 通知 UI
         - 备注面板中滚动到对应条目
         - 高亮该条目
         - 同时执行方案 A
```

推荐 **方案 A**（画布临时浮窗），因为用户明确要求浮窗出现在"编号点附近"。方案 B 可作为辅助增强。

**浮窗样式规格**:
```
┌──────────────────────────┐
│  ① 这里修改顶部导航栏...  ✕│  ← 右上角关闭按钮
│                          │
│  (支持多行文本，          │
│   最大宽度 260px，        │
│   自动换行)               │
│                          │
│  [编辑] [删除] [锁定]     │  ← 底部操作按钮
└──────────────────────────┘
  • 背景: #FFFFFF, 圆角 8px
  • 阴影: 0 2px 8px rgba(0,0,0,0.15)
  • 字体: 12px, #333333
  • 最大宽度: 260px
  • 位置: 编号点右下方偏移(30, 10)
  • 关闭: 点击 ✕ 按钮手动关闭
```

### 5.9 备注内容编辑（浮窗 + 面板双向同步）

**编辑入口**:
1. 在备注面板中直接编辑对应条目的文本
2. 在临时浮窗中编辑（浮窗内添加编辑按钮，点击后切换为编辑模式）

**同步机制**:
```
浮窗编辑 → 更新 PluginData → postMessage → 面板更新
面板编辑 → postMessage → 更新 PluginData → 浮窗更新
```

两边编辑都通过沙箱层的 `node.setPluginData()` 作为唯一数据源，保证一致性。

## 六、通信协议（postMessage）

### 5.1 沙箱 → UI

| 消息类型 | 载荷 | 说明 |
|---------|------|------|
| `init` | `{ annotations: Annotation[] }` | 初始化，发送所有编号点数据 |
| `annotation-added` | `{ annotation: Annotation }` | 新增编号点 |
| `annotation-removed` | `{ annotationId: string }` | 删除编号点 |
| `annotation-updated` | `{ annotation: Annotation }` | 编号点数据更新（内容/位置/锁定） |
| `annotations-renumbered` | `{ annotations: Annotation[] }` | 重编号后的完整列表 |
| `annotation-selected` | `{ annotationId: string \| null }` | 当前选中的编号点 |
| `selection-cleared` | `null` | 取消选中 |

### 5.2 UI → 沙箱

| 消息类型 | 载荷 | 说明 |
|---------|------|------|
| `add-annotation` | `{ targetNodeId?: string }` | 请求添加编号点 |
| `delete-annotation` | `{ annotationId: string }` | 请求删除编号点 |
| `update-note` | `{ annotationId: string, note: string }` | 更新备注内容 |
| `toggle-lock` | `{ annotationId: string }` | 切换锁定状态 |
| `locate-annotation` | `{ annotationId: string }` | 请求定位到某编号点（滚动视口） |
| `resize-ui` | `{ width: number, height: number }` | 调整 UI 面板尺寸 |
| `collapse-panel` | `null` | 收起面板到浮标态 |
| `expand-panel` | `null` | 展开面板 |
| `panel-state-changed` | `{ state: 'collapsed' \| 'expanded' }` | 面板状态变更通知 |

## 九、待确认与风险点

### 8.1 需要进一步确认的问题

1. ~~**"鼠标指定位置"的实现方式**~~ → ✅ 已确认：方案 C（有选中图层则编号点出现在图层旁边，无选中则出现在视口中心，随后拖拽微调）

2. ~~**备注浮窗的生命周期**~~ → ✅ 已确认：手动关闭，浮窗右上角 ✕ 按钮关闭

3. ~~**多个编号点绑定同一目标图层**~~ → ✅ 已确认：允许，一个图层可以有多个编号点

4. ~~**跨页面/跨 Frame 的编号点**~~ → ✅ 已确认：同一个备注面板内所有编号点全局连续编号（不分页面，统一从 1 到 N）

5. ~~**插件关闭后状态保持**~~ → ✅ 已确认：PluginData 随文件保存可接受，协作者需安装插件才能使用完整功能

6. ~~**编号点归属（Page 级别）**~~ → ✅ 已确认：直接放在当前 Page 下，与目标图层同级，通过命名前缀 `[Annotation]` 识别

### 8.2 已知限制

| 限制 | 影响 | 应对 |
|------|------|------|
| 无法添加画布右键菜单 | "右键删除"不可行 | 改为选中 + Delete 键 / 面板按钮删除 |
| 无法编程控制插件窗口位置 | 面板"锁定"无法阻止 Figma 原生的窗口拖拽 | 视觉锁定标识，内部状态控制 |
| 无法捕获画布鼠标坐标 | 不能"点击画布位置直接放置" | 创建后拖拽定位 |
| `documentchange` 高频触发 | 位置跟踪可能影响性能 | 节流处理（debounce） |
| 协作者无法触发 `documentchange` | 多人协作时位置跟踪不实时 | 插件打开时全量重算位置 |

### 8.3 技术选型

- **语言**: TypeScript
- **构建**: 不需要额外构建工具（Figma 原生支持 TypeScript，通过 `@figma/plugin-typings`）
- **UI 框架**: 原生 HTML/CSS/JS（插件 UI iframe 体积限制，不建议引入大框架）
- **存储**: Figma PluginData API（`node.setPluginData` / `node.getPluginData`）

## 十一、实际实现变更记录

以下为开发过程中相对原始方案的实际变更，**以本节为准**：

### 11.1 功能变更

| 原始方案 | 实际实现 |
|---------|---------|
| 放置模式（鼠标点击画布放置编号点） | **已移除**。添加编号点必须先在画布选中图层，编号点生成在图层左上角并自动绑定 |
| 右键删除编号点 | 画布 Delete 会触发**删除保护**（从备份恢复编号点，提示"请通过插件面板删除"）。删除只能通过面板 🗑 按钮 |
| 手动关联/改关联（覆盖层点击图层） | **已移除**。改为**位置自动关联**：编号点拖到哪个图层内就跟哪个图层关联，拖到空白处自动解除 |
| 临时浮窗（点击编号点弹出，手动关闭） | 保留，增加 **auto/click 双模式**：auto=图层右侧排列（8px 间距），click=点击编号点临时查看；选中其他内容浮窗回到图层右侧 |
| 备注编辑（浮窗 + 面板） | **仅面板可编辑**，浮窗只读展示；输入防抖 300ms + 失焦立即保存，编辑中不重渲染（支持中文输入法） |
| 浮窗固定宽度 240px | 改为**可配置**（每行字符数 × 标准字符宽 7px，范围 8-60 字） |
| 编号点固定 24px 蓝色 | 改为**全局可配置**：12 色预设色板 + 尺寸 12-60px + 备注字号 10-16 |
| — | **新增搜索栏**：输入编号精确匹配，列表实时过滤 |
| — | **浮窗置顶**：新建编号点的浮窗自动移到最顶层 |
| — | **删除保护恢复增强**：恢复前查重（防 Ctrl+Z 重复）、锁定状态写入备份 |

### 11.2 锁定防护范围（增强）

锁定编号点后，以下操作全部被阻止并自动复位：
- 拖拽移动（位置）
- 缩放（尺寸）
- 水平/垂直翻转（变换矩阵，含定时轮询兜底 500ms）
- 修改圆形外观（颜色/填充）

### 11.3 技术要点

- 编号点识别：以 `PluginData(ann_id)` 为准（`findAll` 递归扫描），不依赖名称前缀
- 坐标系统：嵌套图层统一使用 `absoluteBoundingBox`（页面绝对坐标）
- 屏幕→画布换算：`world = bounds左上角 + 屏幕偏移/zoom`
- 容器拖拽跟随：用各编号点**直接绑定目标**的实时 bounding box + offset，支持绑定容器内子组件
- 数据备份：所有编号点数据实时备份到 `figma.root` PluginData，用于删除恢复
- 页面切换：`currentpagechange` 时重新同步列表/备份/浮窗
- 已知限制：跨页恢复编号点暂不支持（备份无 pageId）；插件未运行时画布删除无法拦截
